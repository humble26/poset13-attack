## 1. 问题

对有限偏序集 P，e(P) 为线性扩展数，p_P(x,y) = e(P+x<y)/e(P)（x∥y），δ(P) = max_{x∥y} min(p, 1−p)。
**猜想（Kislitsyn 1968）**：P 非全序 ⟹ δ(P) ≥ 1/3。
最强一般结果：Kahn–Saks 1984（δ ≥ 3/11）、Brightwell–Felsner–Trotter 1995（δ ≥ 1/2−√5/10，无穷情形不可再改进）。
本会话主攻 **width-3 情形**：该类无任何一般性结果（height-2 已由 Trotter–Gehrlein–Fishburn 1992 解决；
width-2 由 Linial 1984 解决、Sah 2021 加强），且 Saks 1985 的极值例给出 14/39 > 1/3 的余量。

## 4. 证明全文

### 记号
(P, ≺) 有限严格偏序；x∥y 不可比；线性扩展、e(P)、P+x≺y（加入关系取传递闭包）、
p_P(x,y) = e(P+x≺y)/e(P)、δ(P) = max_{x∥y} min(p, 1−p)。

### 引理 0.1（扩展存在性）
有限偏序必有极小元（无穷递降链与有限性矛盾）；取极小元 m，归纳排 P∖{m}，m 置首。∎

### 引理 0.2（相邻交换）
扩展中相邻的不可比元素可交换仍为扩展：逐一验证涉及 a,b 的五种关系位置情形。∎

### 引理 0.3（前缀是下集）
u 在前缀、v ≺ u ⟹ v 在前缀（v 必须排在 u 前）。∎

### 引理 0.4（p 的组合刻画）
ext(P+x≺y) = {L ∈ ext(P) : x 在 y 前}；P+x≺y 的每个关系要么是旧关系、要么是 x≺y、
要么由传递性导出且 L 满足之。∎

### 引理 A
扩展的最后元素必为极大元；按最后元素分划 ext(P)，"末尾追加 z"给出 ext(P∖z) ≅ E_z 的双射。∎

### 推论 A′（顶部递归）
p_P(x,y) = q_y + Σ_{w∈max(P)∖{x,y}} (e(P∖w)/e(P))·p_{P∖w}(x,y)，q_y = e(P∖y)/e(P)。
（按最后元素 w = y / w = x / 其它三种情形分块计数。）∎

### 引理 B（临界对覆盖）
临界对 (x,y)：x∥y 且 D(x)⊆D(y)、U(x)⊆U(y)。在 P′=P+x≺y 中取扩展 L′（x 在 y 前）。
夹层元素 s：s≺x 排除（s 须在 x 前）；x≺s 排除（U(x)⊆U(y) ⟹ y≺s ⟹ s 在 y 后）；y≺s 排除。
故 s∥x（P′ 中），用引理 0.2 逐步上移 x 贴住 y。每步均为 P（从而 P′）的扩展。∎

### 引理 C（插入权重恒等式）
i_z(M) = #{k : D(z) ⊆ prefix_k(M) 且 U(z) ⊆ suffix_k(M)}。
L ↦ (L∖z, z 的位置) 给出 ext(P) 与 {(M,k) : M ∈ ext(Q), k 合法空隙} 的双射
（合法空隙恰是使插入结果满足全部关系者）；删 z 不改 x,y 相对次序。
故 e(P) = Σ_M i_z(M)，e(P+x≺y) = Σ_M i_z(M)·[x<_M y]，相除即得。∎

注记：z 极大时 U(z)=∅，i_z(M) = |M|+1−t（t = D(z) 在 M 中的最大位次）。

### 命题 1
z 与其余一切元素可比 ⟹ 合法空隙唯一（k = |D(z)|），i_z(M) = 1；
代入引理 C 得 p_P(x,y) = p_{P∖z}(x,y)；width ≤2 母图情形由 Linial 1984 / Sah 2021 承接。∎

### 目标定理（开放）
width(P∖z) ≤ 2 ⟹ δ(P) ≥ 1/3。剩余步骤：证明"平衡守恒"（见第 2 节末条）。

## 7. 第二阶段：守恒机制与理想分解（2026-09-27 会话）

### 已证新结果

**引理 D（理想分解）**：e(P) = Σ_{I} e(I)·e(Q∖I)，I 取遍 Q = P∖z 的理想且 D(z) ⊆ I、I ∩ U(z) = ∅。
证明：L ↦ (before-z 集 I, 前缀扩展, 后缀扩展) 是双射（理想的下封闭性排除 u∉I<v 型矛盾）。

**条带公式**：对 u ∥ z，p_P(z,u) = Σ_{I ∈ box, u ∉ I} e(I)e(Q∖I) / e(P) —— z-对的 p 值恰是
"盒子内避开 u 的理想质量占比"。Python 验证 267/267；Lean 同上验证。

**引理 E（多数传递性 / 等价形式）**：p(x,z) ≥ p(x,y) + p(y,z) − 1 恒成立（并集界）。
故若所有不可比对都不平衡，则"多数关系" χ(x,y): p(x,y) > 2/3 可传——
**目标定理 ⟺ P = Q+z（width Q ≤ 2）不存在"2/3 多数线性扩张"**。

**角点对下界（并集界推论）**：x "低"（x ∈ D 或 x ∥ z 且 p(z,x) < 1/3）且 y "高"
（y ∈ U 或 y ∥ z 且 p(z,y) > 2/3）⟹ p_P(x,y) ≥ P(x∈I, y∉I) ≥ 1/3。

## 9. 第三阶段：守恒机制解剖（2026-10-03 会话）

目标：把"平衡守恒"写成可证命题。记 Q = P∖z（width ≤ 2），链分解 A = (a₁..a_s)、B = (b₁..b_t)，
盒子 box = {(i,j)}：理想 I(i,j) ⊇ D(z)、I(i,j) ∩ U(z) = ∅，μ(i,j) = e(I)e(Q∖I)/e(P)（引理 D 权重）。

### 新增已证引理（数值验证全覆盖）

**θ-结构（引理 F）**：定义 θ(x) = p_P(z,x)（x∈D 时 0，x∈U 时 1，x∥z 时为条带公式累积质量）。
θ 沿每条链单调不减；z-不可比窗口是链上**连续区间** (i_D, i_U]（D∩链 = 前缀，U∩链 = 后缀）。
失败情形（z-对全不平衡）⟹ 存在干净切割 i* ∈ [0,s]、j* ∈ [0,t]：θ < 1/3 于下侧、θ > 2/3 于上侧，
即累积质量沿窗口**跳过 [1/3,2/3]**。（条带公式 + 单调性，E9/E11 断言全程通过。）

**重层 + 挤压（引理 G，E7 观察提升为定理）**：失败 ⟹ 盒子存在质量 > 1/3 的列或行（"重层"）；
且在 θ-跳跃列 c：colmass[c] > 1/3 且 M_A(c) ∈ (2/3 − colmass[c], 1/3)——被挤进宽度 < colmass 的窄缝。
验证：n=4,5 穷举 2330/2330 + 挤压 134/134；n=4,5 穷举 + n=6 采样合计 12067/12067、611/611（E17）。

**三明治（引理 H，一般工具）**：任意有限偏序集、任意不可比对 (x,y)：
P(y 排末尾) ≤ p_P(x,y) ≤ 1 − P(x 排末尾)；推广：p ≥ P_L(y ∈ top-j, x ∉ top-j)。
（由引理 A′ 逐步剥离极大元。）推论：P(y 末尾) ≥ 1/3 时 (x,y) 自动下侧平衡（P(x 末尾) ≤ 2/3 免费得）。
极值案例在三明治处**取等**（见下）。

**账本恒等式**：对不可比对 (x,y) ⊂ Q，
p_P(x,y) = μ{x∈I,y∉I} + Σ_box μ(i,j)·p_{I(i,j)}(x,y) + Σ_box μ(i,j)·p_{F(i,j)}(x,y)，
其中走廊内概率由路径 DP 精确计算。E16 验证 1576/1576（账本和 ≡ pval，硬断言）。

**M-帧重加权（引理 C 特化，E19 验证 313/313）**：p_P(x,y) = Σ_M gap(M)·[x <_M y] / Σ_M gap(M)，
M 取遍 ext(Q)，gap(M) = z 的合法空隙数 = ν − t（t = D(z) 在 M 中的最大位次，ν = U(z) 的最小位次，
全 D 先于全 U 时为正否则 0）。即：z 的存在把 Q 上的均匀测度重加权为"偏爱 D–U 间隙大"的测度。
**Δ-恒等式（E19 验证 135/135）**：链上相邻 a_k ≺ a_{k+1} 与任意 b_l：
p(a_k,b_l) − p(a_{k+1},b_l) = P_L(b_l 严格介于两者)——纯逻辑恒等式，是边界游走步长的度量。

### 机制结论（账本解剖）

平衡的来源是 **crossing 质量 + 走廊内 p_I 值的联合校准**，不是并集界：
例 1（P = 0≺1≺z + 孤立元 3）：p(a_{i*},b_{j*}) = 1/4·1 + 3/4·(1/3) = 1/2；
例 2（链 + 孤立元、z 在底）：p = 4/5·(3/4) + 1/5·0 = 3/5。
z-切割分离只对**跨侧**（低×高）对给单侧界（p > 1/3，对偶给 p < 2/3——同一信息）；
**同侧对的界必须来自盒子内部结构**——即 Linial 定理在切割内部"平均后存活"。
这把守恒引理精确化为：**同侧角块内存在账本值落入 [1/3,2/3] 的不可比对（S1）**。

### E24/E25：中心对称的存活范围与亏缺公式（2026-10-03 续二）

**Φ-双射与亏缺公式**：Φ = 逆序 + 链内重标签（aᵢ ↦ a_{s+1−i}, bⱼ ↦ b_{t+1−j}）。
对 P = Q+z 的 gap-加权测度（引理 C 权重）：

  p_P(k,l) + p_P(s+1−k, t+1−l) = 1 + d(k,l)，
  **d(k,l) = Σ_M (gap(M) − gap(Φ(M)))·[a_k <_M b_l] / e(P)**

——破缺是**所有格共享的同一个带号权差场** Δw = gap − gap∘Φ（对 k,l 只经指示函数进入）。
E24 实测（401 个多切割失败案例）：d ∈ [−1/2, 3/7]，双向皆有；单格位移 p_P − p_Q
正 558 / 负 477 / 零 34——重加权效应真实且非单向。

**中心对称的精确存活条件（E25 修正）**：Φ 保持 ext(Q) 当且仅当 Q 有**镜像反自同构**
（x ≺ y ⟺ Φ(y) ≺ Φ(x)——自由走廊恒成立；随机 cross 关系一般破坏，E25 首版命题
因此被自己的构造否证：504 bad / 42 ok，ok 者恰为无 cross 关系或对称者）。
在此条件下再要求 z **居中**（Φ(D) = U ∧ Φ(U) = D，即 iD = s−iU ∧ jD = t−jU），
则 gap∘Φ = gap 逐点成立，**d ≡ 0：中心对称在 P 中精确存活**。

**可证管线（新确定的定理子情形）**：Q 有镜像反自同构 + z 居中 + s,t 均奇 +
中心格不可比 ⟹ 中心格 p = 1/2 精确平衡（对称 + 自反）——目标定理该子情形完成。
剩余难点随之聚焦：**无反自同构的一般走廊**（亏缺场非零）如何仍强迫平衡——
这是 S1 的真正机制所在，亏缺场的符号结构（E24 显示双向）说明它不是简单的推力，
需要与 θ-切割/重层挤压联合的论证。

**(i) 四轮：9.E 机制 + |W| = 1 子情形的完整证明（定理 9.G）**

**(k) 五轮：|W| = 2 的证明（定理 9.I，第七个关闭子情形）**

把 9.G 的路线推广到 |W| = 2，先建立两个**一般性已证事实**（引理 9.H，对任意 |W| 成立）：

1. **后缀性**：对任意 w ∈ W，{d ∈ D : d ∥ w} 是 D 的后缀 [α(w), r]（若 w ≺ d 则
   w ≺ d ≺ z，与 w ∥ z 矛盾）；
2. **账本分解**：p_P(d_i, w) = Σ_I μ(I)·p_I(d_i, w)，d ∈ D 时 d 恒在 I 中。

分两情形：

- **链盒（w₁ ≺ w₂）**：box 三点。用显式计数（先插 w₁ 槽 s，再插 w₂ 须在
  max(d_{α₂−1}, w₁) 后）推出 e(I₂) 与 #(d_i ≺ w₁) 的闭式（**r ≤ 5 全参数 55/55 + 140/140
  验证**），从而 p_{I₂}(d_i,w₁) 单调、跨度 ≥ 1/2，失败 ⟹ m₁ ∉ [1/3,2/3] ⟹ 凸组合
  必扫过区间。n=7 链盒 9068 例全过、w₁-扫过 8836 零失败。
- **不可比对（w₁ ∥ w₂）**：box 四点。**关键刚性**（n=7 全部 844 例）：**{m₁,m₂} =
  {5/18, 13/18}**（780 + 64 镜像），5/18 < 1/3、和 = 1。取 m=5/18 的一侧套 9.G 路线。
  844 例全部有 DW/WU 见证。

**9.E 案例树更新**：|W| ∈ {0,1,2} 全部关闭（0 = z-孤立 9.A、1 = 9.G、2 = 9.I）。
唯一剩余 |W| ≥ 3，且 n=7 穷举显示无 DW/WU 见证的例外**全部 |W| = 4**、结构"2 低 + 2 高"、
